# Subtitler workflow rules — 0.8.1

1. **Open projects through File or double-click.** New creates a separate document window. Open/Open Recent and Finder open saved `.subtitler` files. An untouched empty startup window is reused; the same already-open path is focused. Closing one document does not close the others.
2. **Import into the current document.** File → Import → Audio attaches a recording; Reference text imports TXT/DOCX/supported shared reference or pasted text separately; Subtitles imports SRT/supported timing JSON while preserving the audio. Dropping files works in the receiving window.
3. **Choose the job from the content.** Transcribe recognizes the audio and automatically attempts precise word alignment. Match timings appears centrally when reference text and audio are present, then hides after successful matching/alignment. Changed spoken words show Update word timings in the main control bar; punctuation-only changes do not require it. Alignment failure retains recognized text and offers retry.
4. **Save portable audio with the project.** Cmd/Ctrl+S/Save project embeds the recording's original bytes without moving or modifying the source. New self-contained documents no longer depend on the former source location. Older JSON files remain readable; if they never embedded the audio, attach an accessible recording and save to make them portable.
5. **Each opened path is its write target.** Save As makes an independent standalone copy. A copied file opened at a different path receives independent transcript ownership and cannot silently write through the previous file's Storyboard connection. The app does not search the entire computer for missing paths.
6. **Use one dedicated Subtitler save folder.** Standalone and connected documents normally save there, defaulting to Desktop/Subtitler. File → Move Subtitler folder selects a new parent, copies/verifies the folder safely and updates known saved/recent/connected references. Saved location is shown below Save/Export; intentional Storyboard connections are brighter.
7. **Storyboard Studio requests specify the recording.** Match timing with Subtitler passes the chosen audio and project folder. The explicit recording wins. If inaccessible, locate/import it manually; another recording is never silently substituted.
8. **One transcript per connected recording.** Reuse/update the existing .subtitler for that recording in the configured Subtitler folder. Studio Link keeps document references and a current timing handoff, plus per-recording timing records. A standalone document cannot silently take over a connected recording. Publishing uses the same workflow lock as Storyboard Studio.
9. **Recover audio when the editor needs it.** Subtitler plays its embedded copy. Storyboard Studio/video editors still need an ordinary readable audio file. Storyboard Studio offers Locate audio or Recover audio from Subtitler project; recovery verifies identity and writes a usable copy only when requested.
10. **Undo edits, not external deletion.** Clear reference and Clear transcript are separately undoable. Clearing a linked transcript explicitly clears its current handoff. Deleting source files is never part of clearing text. A document that never preserved audio cannot invent missing bytes.
11. **Keep simultaneous jobs bounded.** Windows are independent, but native transcription/alignment shares an exclusive worker. Finish/cancel one job before another window starts a new one. Quit waits for saves and does not silently discard a failed save.
12. **Install and test native launching.** The update retains `local.filipe.whisperdesk`, refreshes the installed macOS file association and uses an OS-released startup lock. The supplied frontend is prebuilt; Rust 1.89+ is required for native builds. Actual Finder/Windows file association and native GUI behavior need target-system testing.
