# Portable Subtitler project format — 0.8

Normal and Storyboard-connected `.subtitler` documents use the same self-contained format and configured Subtitler save folder. Original audio is copied without re-encoding or editing it. Runtime playback uses a reusable verified cache; temporary cache extraction is not another editable transcript.

The container starts with `SUBAUD2\n` (8 bytes), an unsigned 64-bit little-endian audio length, and the exact audio bytes. Remaining records each contain UTF-8 checkpoint JSON, its unsigned 64-bit little-endian byte length and FNV-1a-64 checksum, and the 8-byte trailer `SUBJSON2`. Checkpoint JSON contains `format: subtitler-container-v2`, `project` (existing whisperdesk-project-v1 metadata) and `audio` (name, length, full-byte hash, recording fingerprint), or null audio for text-only projects. Checksums detect accidental corruption; they are not cryptographic signatures.

Readers validate bounds and checksum, selecting the most recent complete checkpoint. An interrupted final append falls back to the preceding complete checkpoint. Metadata edits append without recopying audio. Unchanged saves do not write. When the journal exceeds both 32 MiB and eight times current JSON size, a temporary replacement compacts it. Changing the recording also uses a temporary replacement. The previous file remains available until replacement is ready; Windows replacement uses a rollback file.

Source audio identity remains independent of transcript/document identity. `source.embeddedPath` is runtime-only and not stored in project metadata or counted as an edit. `source.path` preserves the original reference for interoperability. Subtitler processes its own recording copy; unrelated imports do not inherit Studio Link. Copied files become independent documents under the existing path-ownership rule.

Legacy JSON `.subtitler` and `.whisperdesk` files remain readable. Saved text renders even when audio is unavailable. Saving upgrades the container; missing audio must be located before it can be embedded. Self-contained files need Subtitler 0.8 or later: older versions understand only JSON projects.

Studio Link stores the normal document path in its registry and timing handoff, plus one active timing handoff and retained per-recording history. Storyboard Studio 0.11.1 can restore that recording into the project folder when requested. Recovery verifies identity/checksum and never overwrites different existing audio; exclusive creation supports filesystems without hard links.

File → Move Subtitler folder chooses a new parent, retaining the folder's name. Native document I/O is serialized. Files are staged and byte-compared, document paths and known current/historical Studio Link references are updated, and only then is the old folder removed. Failed reference updates retain the original and roll back completed updates. Known moves redirect queued saves and notify all open windows. Explicit Save As files outside the moved folder stay where chosen. Existing destination folders are never merged. General user/system/Storyboard roots, symbolic links and unsafe nesting are rejected.

Transcribe performs recognition, optional reference comparison and final WhisperX word alignment. Match timings appears centrally only for reference text plus audio and hides after successful matching/alignment. Matching an existing imported transcript preserves its division. Word edits reveal one global Update word timings control; it never recognizes text again. Punctuation/capitalization do not require another alignment. Failure retains usable existing recognition and offers Retry. Manual timing remains protected by default.

Optional `chapters` metadata is an array of stable IDs, titles, heading levels 1–6, and `start` seconds or null when unplaced. `timeMode` distinguishes manual times from matched word anchors; `origin` and `referenceId` track imported headings. `anchorWordId` follows the current timed word, rather than a mutable array position. `needsReview` excludes a manual timestamp after a recording replacement until the user reviews it. Older projects without this field open with an empty chapter list. Chapter metadata uses the existing project/checkpoint container and recording identity; no extra audio copy or shared timing file is created for chapters. Timing JSON carries this optional metadata without changing its existing format identifier.
