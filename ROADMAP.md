# Subtitler roadmap

## Completed in 0.4.0

Unified import; .subtitler files with legacy support; light/dark theme and themed scissors; full-width waveform; General/Transcription Models settings and shortcuts; text cancel/Enter/blur semantics; timing autosave; project context exports, close/delete/all actions; configurable subtitle division; automatic optional WhisperX alignment; script-assisted recognition/comparison; quiet-interval detection and marker handoff; optional speaker labeling; automatic English/Japanese alignment switching with passage override; shared project-folder saves and Studio Link script/timing discovery.

## Deferred

MOV/MP4 import, subtitle styling/fonts/effects and rendered visual subtitles over video. Keep these for a later full update.

Native M1/Windows runtime verification, mixed-language accuracy comparisons and actual multi-speaker model inference still require device/recording validation. Timing is an initial editing aid, not a promise of perfect boundaries.

Timeline assembly/export belongs in Storyboard Studio. Its recording dropdown and incremental chapter-export workflow are queued for removal when Storyboard Studio work resumes. Do not add an editor connector to this Subtitler release.
